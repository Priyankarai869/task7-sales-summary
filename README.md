# Task 7 - Sales Summary Using Python and MySQL<br><br>

##  Objective<br>
Connect Python to MySQL and generate a basic sales summary using SQL queries and matplotlib bar chart.<br><br>

##  Tools Used<br>
- Python (pandas, matplotlib, mysql-connector-python)<br>
- MySQL (via MySQL Command Line Client)<br>
- GitHub for submission<br><br>

##  Files Included<br>
- `sales_summary.py` – Main Python script<br>
- `sales_table.sql` – MySQL script to create table and insert data<br>
- `sales_chart.png` – Bar chart of sales revenue<br><br>

##  How to Run<br>
1. Import `sales_table.sql` into MySQL<br>
2. Update MySQL credentials in `sales_summary.py`<br>
3. Run the script using: `python sales_summary.py`<br>
